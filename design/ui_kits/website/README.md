# Event site UI kit

Interactive recreation target for the DigiResiThon static site (the site doesn't exist yet — this kit *defines* it).

- `index.html` — mounts `Website` (nav + view switch + footer + register dialog). Blackout theme by default; the nav toggle flips `data-theme="light"`.
- `Website.jsx` — shell: sticky nav (logo, HOME/SCHEDULE/PROJECTS, StatusDot, theme toggle, Register), footer, RegisterDialog (form → terminal ACK).
- `Landing.jsx` — hero (pixel headline + terminal + one red slash + scanlines), marquee ticker, stats strip, tracks grid, who-should-come.
- `Schedule.jsx` — day tabs, box-drawing timetable, blackout-drill alert, packing checklist.
- `Projects.jsx` — filter tabs + `$ grep` search, project cards with SYNC signal bars, dashed "your idea" slot.

All dates/venue/stats/projects are **sample data** (see `Shared.jsx` `SAMPLE`) — replace with real event facts.

Note: pages load `_ds_bundle.js` (generated by the design-system compiler) and fall back to `ds-runtime-fallback.js` (fetch + Babel-transpile the JSX sources) when the bundle is absent, so the kit runs either way.
